# Interface

- Em novas interações de UI, leia a skill `.agents/skills/ui-sdk/SKILL.md` e a documentação instalada em `node_modules/@ui-sdk/core/docs/llms.txt`.
- Use o UI SDK para comportamentos que exigem gestão de foco, teclado, seleção ou anúncios. Não substitua um controle HTML nativo sem necessidade.
- Componentes permanecem Astro e TypeScript; não adicione Svelte. Teste teclado, foco visível, tema escuro e largura de celular.
- Preserve textos em português e a identidade de `src/lib/site.config.ts`.
